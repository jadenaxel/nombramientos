# Índice de trazabilidad de aceptación

Este índice enlaza los criterios normativos `AC-01` a `AC-38` de [`prompt.md`](../prompt.md) con implementación y pruebas fuente del repositorio. No sustituye la [matriz de aceptación](acceptance-matrix.md), el [registro de verificación](verification.md), la guía de [autenticación enterprise](authentication.md) ni las [limitaciones conocidas](known-limitations.md). El verify integral vigente y el real-stack vigente aprobaron en el laboratorio local; continuidad, anclaje y reinicio tienen cortes históricos separados. “Aprobado localmente” nunca implica certificación o autorización de producción.

```powershell
$env:NOMBRAMIENTOS_REQUIRE_LIVE_INTEGRATION = 'true'
```
