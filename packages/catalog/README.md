# @nombramientos/catalog

Catálogo institucional y matriz normativa versionados para la plataforma.

## Alcance y cautelas

- La revisión canónica de contenido es `2025.1.0`: contiene 29 departamentos y 67 oficinas/cargos y parte del *Seventh-day Adventist Church Manual*, 21.ª edición revisada en 2025, consultado en inglés en la URL oficial indicada en `sources.ts`.
- `2025.1.0` identifica la revisión del contenido; el estado del paquete institucional continúa siendo `draft` mientras la aprobación denominacional/regional permanezca pendiente. No debe presentarse como catálogo aprobado para Ozama.
- Los textos ES/EN/FR son etiquetas y resúmenes de trabajo para la aplicación. No son traducciones oficiales del Manual de Iglesia.
- `verified_primary_source` significa que la referencia primaria y el pasaje indicado fueron cotejados; no significa validación por una asociación, misión, unión, división, asesoría jurídica o auditoría externa.
- `pending_regional_validation` y `pending_primary_source_validation` impiden presentar el elemento como una obligación universal.
- Ozama debe confirmar asociación/misión, unión, división, terminología y prácticas locales antes de promover esta versión a catálogo aprobado del tenant.
- No se redistribuye el texto completo de los manuales. La aplicación debe enlazar a las fuentes oficiales salvo que exista autorización documentada.

El historial de un ciclo debe conservar la versión exacta de este paquete y no cambiar cuando se publique una versión posterior.
